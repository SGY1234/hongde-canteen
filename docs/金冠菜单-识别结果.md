## 二、已定的事

> ✅ 已解决：「荔枝鸡」10 道补全；「鸡架拌面」是水饺；「小爆炒同学」14 道补齐（18秒鸡胗、山野真菌小炒、蜜汁酥糖鸡、客家小炒肉、腊肉豆干、麻辣豆腐、乡村一碗香）；「牛肉汤烧饼」6 道；「马家胡同」12 道；「小馋猫」36 道。

### 称重类怎么写（已定）

这三家是**按斤称**，没有固定价格：

- 付佳佳麻辣烫 → 17.8 元/斤
- 航语佳烤盘饭 → 9.9 元起
- 川渝自选菜（小张二楼，已录）→ 1.78 元/50克

**决定（2026-10-19 18:20）：改成带单位的写法。**

前端 `public/app.js` 里的 `priceText()` 函数已经支持 `unit` 字段，它会拼成「数字 + unit」，unit 没填就默认「元」。所以菜单数据里这样写：

```json
{ "name": "麻辣烫", "price": 17.8, "unit": "元/斤" }
{ "name": "烤盘饭", "price": 9.9,  "unit": "元/斤起" }
```

页面就会显示成「17.8元/斤」，同学不会误会成一份的价格。

## 四、我建议这样处理

| 情况 | 建议 |
| --- | --- |
| 称重类（麻辣烫/烤盘饭/自选菜） | 价格栏写「17.8元/斤」这样的文字，不写纯数字 |
| 加料类（芝士片 +2 等） | **不单独成菜**，同学不会给"加料"打分 |
| 大份/小份、大碗/小碗 | 合并成一道菜，价格写「8~12元」区间 |
| 粥/汤/饮料 | 保留，同学也会想打分 |
